Supabase gives you a Postgres database in the cloud. Django talks to it like any other Postgres database, so you don't need the Supabase JavaScript client.

  • You need: a free Supabase project
  • Time: about 10 minutes
  • Result: Django tables live in Supabase

  1. Create a project and open Connect

    1. Open supabase.com and create a project
    2. Save the database password you choose
    3. Click Connect at the top of the dashboard
    4. Pick Session pooler

  2. Why the user and host look different

    Supabase shows two kinds of connection. Use the Session pooler.

    Direct Session pooler
    Host db.xxxx.supabase.co aws-0-region.pooler.supabase.com
    User postgres postgres.xxxx
    Works on Wi-Fi? Often no (IPv6 only) Yes (IPv4)

    Why .xxxx? Many projects share the pooler, so the user name carries your project id.

  3. Install the Postgres driver

    Terminal 
    pip install "psycopg[binary]"

  4. Put the values in .env

    .env 
    SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres.your_project_ref
SUPABASE_DB_PASSWORD=your_password
SUPABASE_DB_HOST=aws-0-ap-northeast-2.pooler.supabase.com
SUPABASE_DB_PORT=5432

    Use your own host: copy it from the Connect screen. The region part differs per project.

  5. Point Django at Supabase

    config/settings.py 
    DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': os.environ.get('SUPABASE_DB_NAME', 'postgres'),
        'USER': os.environ.get('SUPABASE_DB_USER', 'postgres'),
        'PASSWORD': os.environ.get('SUPABASE_DB_PASSWORD', ''),
        'HOST': os.environ.get('SUPABASE_DB_HOST', ''),
        'PORT': os.environ.get('SUPABASE_DB_PORT', '5432'),
        'OPTIONS': {'sslmode': 'require'},
    }
}

  6. Create the tables

    Terminal 
    python manage.py migrate
python manage.py createsuperuser

    Check it: in Supabase, open Table Editor. You will see auth_user and pages_photo.
