Cloudinary keeps the image file. Django only stores the Cloudinary link. Your CSS and templates stay in this project.

  • You need: a free Cloudinary account
  • Time: about 10 minutes
  • Result: uploads appear on the home page

  1. Create a free account

    1. Open cloudinary.com and sign up
    2. On the dashboard, find Cloud name, API key, and API secret

    Keep it secret: the API secret is like a password. Never push it to GitHub.

  2. Install the packages

    Terminal 
    pip install cloudinary django-cloudinary-storage Pillow python-dotenv

  3. Put your keys in .env

    Create a file called .env next to manage.py:

    .env 
    CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

  4. Add the apps in settings

    config/settings.py 
    INSTALLED_APPS = [
    # ... Django apps ...
    'django.contrib.staticfiles',
    'cloudinary_storage',
    'cloudinary',
    'pages',
]

  5. Read the keys and send uploads to Cloudinary

    config/settings.py 
    import os
from dotenv import load_dotenv

load_dotenv(BASE_DIR / '.env')

CLOUDINARY_STORAGE = {
    'CLOUD_NAME': os.environ.get('CLOUDINARY_CLOUD_NAME', ''),
    'API_KEY': os.environ.get('CLOUDINARY_API_KEY', ''),
    'API_SECRET': os.environ.get('CLOUDINARY_API_SECRET', ''),
}

MEDIA_URL = '/media/'

STORAGES = {
    'default': {
        'BACKEND': 'cloudinary_storage.storage.MediaCloudinaryStorage',
    },
    'staticfiles': {
        'BACKEND': 'django.contrib.staticfiles.storage.StaticFilesStorage',
    },
}

    What this does: uploaded files go to Cloudinary, while CSS stays local.

  6. Create a Photo model

    pages/models.py 
    from django.db import models


class Photo(models.Model):
    title = models.CharField(max_length=100)
    image = models.ImageField(upload_to='photos/')

    def __str__(self):
        return self.title
    pages/admin.py 
    from django.contrib import admin

from .models import Photo

admin.site.register(Photo)
    Terminal 
    python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser

  7. Show the image on a page

    Upload a photo from /admin/, then use this in a template:

    templates/pages/home.html 
    {% verbatim %}{% for photo in photos %}
    <img src="{{ photo.image.url }}" alt="{{ photo.title }}">
{% endfor %}{% endverbatim %}

    Check it: right-click the image and open it. The address starts with res.cloudinary.com.
