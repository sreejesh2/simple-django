Today everyone uses this laptop over the Wi-Fi. Render is the next step: a public link that works from anywhere. This is a class demo, not a production setup.

  • You need: GitHub and a free Render account
  • Time: about 15 minutes
  • Result: a link like your-app.onrender.com

  1. Know who does what

    • Render runs the Django website
    • Supabase stores the rows (title, image path)
    • Cloudinary stores the image files

  2. Add Gunicorn

    Your laptop uses runserver. Render needs a real web server called Gunicorn.

    Terminal 
    pip install gunicorn "psycopg[binary]"
pip freeze > requirements.txt

  3. Allow the Render address

    config/settings.py 
    ALLOWED_HOSTS = os.environ.get('ALLOWED_HOSTS', 'localhost,127.0.0.1').split(',')

  4. Push the code to GitHub

    Terminal 
    git init
git add .
git commit -m "class django demo"
git branch -M main
git remote add origin https://github.com/your-name/your-repo.git
git push -u origin main

    Check first: .env must be in .gitignore so your keys stay private.

  5. Create a Web Service

    On render.com: New → Web Service → pick your repo.

    Build command 
    pip install -r requirements.txt
    Start command 
    gunicorn config.wsgi:application

  6. Add environment variables

    In the service, open Environment and add the same names as your .env:

    Render → Environment 
    ALLOWED_HOSTS=your-app.onrender.com
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres.your_project_ref
SUPABASE_DB_PASSWORD=
SUPABASE_DB_HOST=aws-0-ap-northeast-2.pooler.supabase.com
SUPABASE_DB_PORT=5432

  7. Create tables and open the site

    In the Render Shell tab:

    Render Shell 
    python manage.py migrate
python manage.py createsuperuser

    Free plan: the app sleeps when idle, so the first visit can take about a minute.
